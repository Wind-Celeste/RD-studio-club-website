关于我们 ​

🎮 社团介绍 ​

RD STUDIO 是一个热爱游戏开发的学生组织，我们致力于：

  • 技术分享：分享游戏开发技术，包括引擎使用、编程技巧、美术制作等
  • 学习资源：提供丰富的学习资源，帮助新手入门游戏开发
  • 团队协作：组织 Game Jam 活动，团队合作开发游戏项目

📚 我们做什么 ​

技术分享 ​

我们定期举办技术分享会，内容涵盖：

  • Unity / Godot / Unreal Engine 使用教程
  • C# / GDScript / C++ 编程技巧
  • 游戏美术设计（2D / 3D）
  • 游戏音效制作

Game Jam ​

我们组织和参与各种 Game Jam 活动：

  • 社团内部 Game Jam
  • 校级 Game Jam
  • Global Game Jam

项目开发 ​

我们鼓励社员参与游戏项目开发：

  • 个人项目
  • 团队项目
  • 社团项目
